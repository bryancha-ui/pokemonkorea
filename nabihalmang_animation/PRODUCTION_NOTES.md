# 제주 분화구 나비할망 등장씬 제작 노트

## 목표

첨부된 `기라티나 등장씬.mp4`의 고각 전경 → 인물 반응 → 낮은 각도의 실루엣 등장 → 전신 공개 → 최종 영웅적 와이드 숏 흐름을 참고하되, Pokemon Korea의 제주 분화구 사건과 고유 캐릭터로 새롭게 구성한다.

## 게임 기준

- 장소: 제주 화산 분화구 정상, 검은 현무암·용암 균열·증기 분출구·재가 날리는 환경
- 전설 포켓몬: 나비할망 한 마리
- 나비할망 외형: 담청색·크림 금색·먹색·연분홍 금속성 단청 날개, 빛나는 페어리 비늘
- 등장 인물 6명: 여자 주인공, 남자 라이벌, 려 사령관, 수리 디렉터, 노스단 요원 2명
- 장치: 육각형 구속 필드와 황동·강철 고정 장비
- 사건: 나비할망이 구속 필드를 파괴하고 날개를 펼친 뒤, 주인공을 시험하듯 수호자 자세로 떠오른다.

## 30초 영상 구조

| 시간 | 화면 | 음향 |
|---|---|---|
| 0–2초 | 고각 분화구 전경, 장치로 천천히 하강 | 화산 바람, 저음 드론 |
| 2–5초 | 려 사령관과 여자 주인공 반응 숏 | 오케스트라 진입, 현무암 진동 |
| 5–8초 | 구속 장치와 보랏빛 에너지 상승 | 금속 장력음, 에너지 험 |
| 8–11초 | 나비할망 실루엣이 수직으로 상승 | 저음 상승, 페어리 비늘 차임 |
| 11–15초 | 필드 파괴, 인물들이 충격파에 버팀 | 파괴음, 첫 번째 나비할망 울음소리 |
| 15–20초 | 나비할망이 균형을 잡고 날개를 전개 | 금속 날개 공명과 바람 |
| 20–24초 | 려 사령관·주인공 반응 및 날개 디테일 | 음악 재상승, 스파크 |
| 24–30초 | 단청 날개 완전 전개, 최종 와이드 숏 | 두 번째 울음소리, 오케스트라 종결 |

## 연속성 제한

- 전 구간 나비할망은 반드시 한 마리만 존재한다.
- 한 몸·한 머리·큰 윗날개 한 쌍·작은 아랫날개 한 쌍을 유지한다.
- 사람은 여섯 명만 존재하며, 새 인물·복제 인물·합쳐진 인물을 허용하지 않는다.
- 기라티나 및 참고 영상의 기존 인물·워터마크·대사는 복제하지 않는다.
