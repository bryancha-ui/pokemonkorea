# Pokemon Korea 엔딩 크레딧 제작 노트

## 최종 구성

- 러닝타임: 정확히 5분(300초)
- 화면: 1920×1080, 24 fps, 16:9
- 영상/오디오: H.264 High, AAC-LC 48 kHz 스테레오 312 kbps
- 주인공: 여자 주인공 한 명이 같은 빨간 자전거를 타고 계속 전진
- 시간 변화: 새벽 → 오전 → 낮 → 오후 → 노을 → 해질녘 → 밤 → 귀환의 새벽

- 영물: 나비할망, 풍백, 우사, 운사, 환웅을 후반 여정에 배치
- 음악: 게임 원곡의 96 BPM·B♭ 장조 성격을 바탕으로 새로 구성한 120마디 연속 스코어

- 검수 음량: -18.7 LUFS, 최대 -1.5 dBTP
- 음악 처리: 반복 재생을 제거하고 피아노·현악·플루트·호른·합창·타악기로 5분 전체를 새롭게 편곡
- 클라이맥스: 3:50부터 상승, 4:05 부근 최대 음량, 전반부 평균보다 약 11.3 dB 강하게 구성
- 오디오 연속성: 정확히 300초, 2초 이상 비정상 무음 없음

## 참고 기준
